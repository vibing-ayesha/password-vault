# 🔒 Python Password Vault

This is a Python tool that generates highly secure, random passwords and saves them to a local text file so you never lose them.

## Features
- Generates passwords using letters, numbers, and symbols.
- Customizable password length.
- Saves the website and password permanently to `my_vault.txt`.

## How to run it
1. Download the `password_vault.py` file.
2. Open your terminal and run: `python password_vault.py`
